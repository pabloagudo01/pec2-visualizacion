Qué se ha construido

Las tres páginas son archivos HTML independientes que incluyen Plotly en el propio archivo. No necesitan Python en el servidor y funcionan en un alojamiento estático. Los enlaces son relativos, de modo que el sitio puede publicarse en la raíz de un dominio o bajo una ruta de proyecto de GitHub Pages.

La preparación de datos, el cálculo geométrico, la visualización y la validación están separados en módulos de src/ y scripts de scripts/.

Reproducibilidad

  • python scripts/download_data.py: descarga las fuentes.
  • python scripts/build_visualizations.py: genera datos procesados y HTML.
  • pytest -q: ejecuta las pruebas.
  • python scripts/validate_outputs.py: comprueba los archivos publicados.

Fuentes de datos

  • Banco Mundial, World Development Indicators: emisiones de CO₂ totales y per cápita (AR5), 2023. Indicadores EN.GHG.CO2.MT.CE.AR5 y EN.GHG.CO2.PC.CE.AR5. Licencia CC BY 4.0. Ficha del indicador.
  • CORDIS, EU research projects under Horizon Europe (2021-2027). Oficina de Publicaciones de la Unión Europea. Convocatoria HORIZON-CL4-2022-SPACE-01. DOI 10.2906/112117098108/20. Aviso de reutilización de la Comisión Europea.
  • MeteoCat, Metadatos de las estaciones meteorológicas automáticas (XEMA), Generalitat de Catalunya. Conjunto de datos · Aviso legal.

Fecha de consulta: 2026-10-22. Las URL, licencias y cifras se comprobaron antes de construir el sitio. No se usan datos simulados.

Alcance y limitaciones

  • Treemap: el área representa emisiones totales y el color, emisiones per cápita. El cruce dejó 301 registros y se excluyeron 100: agregados regionales o mundiales, grupos de ingreso sin región y economías sin dato o con emisión cero; no se imputaron. El color satura en 25 t/hab para que los valores extremos no oculten el resto.
  • Gantt: cada barra es el intervalo oficial de un proyecto, no una fase inventada. Solo se incluyen los 26 proyectos de la convocatoria HORIZON-CL4-2022-SPACE-01 presentes en la exportación; no hay relaciones de precedencia.
  • Envolvente convexa: el área (36.542 km²) es una superficie proyectada, no una medida de cobertura. Incluye mar y zonas sin estaciones y depende de los puntos extremos.
  • General: las cifras describen los datos descargados en la fecha de consulta; no implican causalidad. El proyecto no se ha publicado en Internet desde este entorno.
